# Jammu&Kashmir

따뜻하고 고급스러운 캐시미어 의류 브랜드 소개용 반응형 홈페이지입니다. React와 Vite로 구현했습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 클라우드 환경에서는 Node.js 24로 검증했습니다.

```sh
cd /workspace/jammukashmir
npm ci
npm run dev -- --port 5173
```

## 배포용 빌드

```sh
npm run build
npm run preview -- --port 4173
```

`dist/`를 정적 호스팅에 배포할 수 있습니다. API 키나 외부 서비스 없이 작동합니다. 이 작업에는 배포가 포함되어 있지 않습니다.

## 구성과 수정

- `src/App.jsx`: 브랜드 문구, 예시 컬렉션, 관리법, 메뉴 및 상세 모달.
- `src/styles.css`: 색상, 타이포그래피, 반응형 레이아웃.
- `public/images/`: 이 프로젝트를 위해 제작한 AI 콘셉트 이미지. 실제 판매 상품 사진으로 교체하세요.
- `public/fonts/`: 로컬 폰트와 각 SIL Open Font License. 한국어 폰트는 전체 한글 음절과 일반 문장부호를 포함한 WOFF2입니다.

실제 상품명·소재 비율·인증·가격·매장 주소·연락처는 제공되지 않았습니다. 컬렉션은 예시이며, 매장과 문의 채널은 준비 중으로 표시했습니다. 브랜드 정보가 확정되면 해당 콘텐츠와 이미지 및 페이지 메타데이터를 수정하세요.

## 기능

반응형 메뉴, 섹션 이동, 컬렉션 분류 필터, 키보드로 닫을 수 있는 상품 상세 모달, 관리법 아코디언을 제공합니다. 주문, 결제, 문의 전송 기능은 포함하지 않습니다.

이 클라우드 작업은 이미 격리된 환경입니다. 기존 체크아웃을 사용하며 별도 Git worktree는 만들 필요가 없습니다.
